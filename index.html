        Relier GitHub (une seule fois)

        Pour publier sur le site, la gestion a besoin d'un jeton GitHub fine-grained (GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens) : propriétaire entarsh-studio, accès au seul dépôt du site, permission Contents : Read and write.

        Dépôt (avancé)
        • Le jeton est vérifié auprès de GitHub avant d'être accepté.
        • Il est rangé dans la base du site, lisible uniquement par un compte gérant.
        • Ensuite, il suffit de te connecter avec ton compte pour gérer, sur n'importe quel appareil.

        Mon compte

        3 à 20 caractères : lettres sans accent, chiffres, - ou _.
